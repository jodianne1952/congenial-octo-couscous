# Scioto County docket data access inquiry

Recipient: sciotoclerkcustomercare@sciotocounty.net
Subject: Inquiry about authorized public docket data access for Ohio Docket Hub

Hello,

We are developing Ohio Docket Hub, a public-facing application intended to help people locate and follow publicly available Ohio court docket information. We would like to learn whether the Scioto County Clerk of Courts offers an authorized API, data feed, bulk export, or other approved technical method for accessing nonrestricted public case and docket information.

If access is available, could you provide the technical documentation, permitted uses, rate limits, update frequency, licensing or fees, and any required agreements? If automated access is not available, please let us know whether linking users directly to the official online records portal is the preferred approach.

We do not intend to access sealed, restricted, or nonpublic records. We will identify the official source and warn users about posting delays.

Thank you,
Ohio Docket Hub team
